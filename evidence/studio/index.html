A review-first evidence library.

The Evidence Studio prepares an optimized image and a JSON record for review. It does not publish directly, because public, unauthenticated uploads would put this portfolio and visitors at risk.

  1. Prepare an image that Muneerah has permission to publish. Blur payment details, identifying third-party messages and sensitive information first.
  2. Download the optimized image and JSON entry. Upload the image into assets/media/ of the official repository.
  3. Add the JSON object to data/evidence.json and commit the changes.
  4. The Git-linked deployment automatically updates the gallery after Vercel finishes building.
